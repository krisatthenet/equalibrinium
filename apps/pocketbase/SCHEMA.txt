================================================================================
  PB_HOOKS SUMMARY
================================================================================

  bid-expiry.pb.js              Cron — marks bids older than N days as
                                "rejected" if still "pending".

  bid-notification.pb.js        On bid create → notify ticket owner (push +
                                email via builder-mailer).

  builder-mailer.pb.js          Shared email-sending helper used by other
                                hooks. Sends via PocketBase SMTP.

  completion-notification.pb.js On Stripe payment webhook → marks ticket
                                "Completed", credits contractor balance,
                                sends notification email (up to 3× risk —
                                BUG-12, not yet fixed).

  cors.pb.js                    Global CORS middleware for pb_hooks routes.

  custom-migrations-cmd.pb.js   Adds `pb migrations up` CLI helper.

  ensure_usertype_values.pb.js  Before save on users → normalises userType
                                to valid enum value.

  external-dashboard.pb.js      Admin-only route for external ops tooling.

  payment-balance.pb.js         On payment create → credits contractor
                                platform balance (users.balance).

  referrals.pb.js               On user create → generates referralCode;
                                processes referredByCode if present.

  sms-notifications.pb.js       On bid / ticket events → sends SMS via
                                external SMS gateway.

  update_contractor_rating.pb.js  On review create → recalculates
                                   users.rating and users.reviewCount for
                                   the reviewed contractor.
